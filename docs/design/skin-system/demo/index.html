02 / 多一点协议，少造一点轮子

          阅读全文 ↗
        

        

          
浏览器负责画。
MXU 负责边界。

          

            不发明新的绘图语言。保留现有主题变量与 React
            业务控件，给皮肤一套稳定的挂载、占位、分层与状态约定。
          

        

        

          

            01 / TOKENS
            
从配色开始

            
沿用现有 CSS 变量。只换颜色、圆角和材质，也是一款完整皮肤。

            CSS custom properties
          

          

            02 / SCENE
            
给表现自由

            
HTML / CSS / SVG 组织角色、背景和动画；复杂媒体用可选适配器。

            HTML + CSS + SVG
          

          

            03 / LAYOUT
            
让布局配合

            
声明锚点、占位和越框区域，由宿主保护按钮、弹窗与窗口边界。

            anchor · reserve · bleed
          

          

            04 / EVENTS
            
对任务有反应

            
接收最小只读状态，通过受控事件响应运行、成功与错误。

            state → visual response
          

        

        

          先做两层，就能玩得很丰富。
          

            L0 主题变量 + L1 声明式场景覆盖本页大多数创意；L2
            隔离脚本留给更复杂的物理、小游戏和外部渲染器。角色位移不等于布局占位，越过面板也不等于越过原生窗口。
