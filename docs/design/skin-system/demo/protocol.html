皮肤，是可编排的界面。MXU Skin Protocol 0.1 · 设计草案

复用 HTML、CSS、SVG 的表现力。MXU 只补上五件事：包加载、语义锚点、布局协商、图层合成，以及受控的状态与动作接口。

01直接使用 Web，但不把业务交给皮肤

MXU 已使用 React 19、TypeScript、Vite、Tailwind、Zustand，以及 Tauri 2 / Axum。建议沿用浏览器渲染器：Grid/Flex 负责排版，CSS 变量负责主题，SVG、CSS animation 和 Web Animations API 负责角色与特效。v0.1 不引入自研渲染引擎、物理碰撞系统或另一套布局语言。

皮肤控制“长什么样、装饰在哪里、什么时候做什么表演”；宿主继续控制“按钮是什么、现在能不能点、点击后发生什么”。启动、停止、设备选择等仍是 MXU 的真实 React 控件，保留键盘操作、无障碍语义与既有业务判断。皮肤不能通过 CSS 选择器依赖 MXU 内部 DOM。

AUTHORskin.json
HTML / CSS / SVG / assets
MXU HOST校验、锚点、占位、图层
受控状态与动作
WEB RUNTIME真实控件 + 隔离装饰层
Grid / Flex / CSS animation

这里的“HTML/CSS 自定义”首先指装饰场景和已公开的样式变量。任意 HTML 接管整棵应用、修改私有业务 DOM，不属于 v0.1 皮肤能力；更高权限的应用插件应另立契约。

02从颜色到会表演的场景

层级 作者提供 能做什么 v0.1
L0 · Tokens JSON 色值、圆角、间距等已注册变量 现有明暗主题、强调色、背景，以及后续开放的控件外观 首先落地
L1 · Scene 受限 HTML/CSS/SVG、本地资源、声明式事件绑定 会动的角色、跨卡片武器、布局占位、任务状态联动 目标能力
L2 · Script 可选隔离脚本与声明的能力请求 程序化动作、复杂状态机、粒子与可选 WebGL 场景 仅预留；不能在 v0.1 加载

作者只需实现自己需要的层级。L1 设计使用 CSS 关键帧、状态属性和宿主事件，就能覆盖实验场六个内置场景的主要表现；不必为了一个眨眼动作写脚本。内置皮肤与用户导入皮肤使用同一份协议，安装来源不自动扩大权限。

      "setSceneState": "mischief" },

字段 约定
schemaVersion / mxu.skinApi 分别标识清单格式与宿主皮肤接口；与皮肤自己的 SemVer version 分离。0.x 不假设跨 minor 兼容。
id / name 稳定的反向域名式标识与多语言名称；同 ID 更新须显式选择，不能静默覆盖另一来源。
capabilities / fallback 缺少 required 则拒绝启用；缺少 optional 则移除相关能力，并按清单降级。本例可只保留 tokens。
tokens 仅接受宿主注册的变量和对应类型；本例色值不能替换为任意 CSS。现有用户的明暗模式偏好继续有效。
placements 将场景元素绑定到语义锚点，声明对齐、偏移、层级、最大越框量和命中方式。所有长度均为 CSS px。
reservations 向宿主边缘槽位申请真实布局空间；size 是请求值，maxFraction 是作者上限，宿主还要施加自身上限。
bindings 白名单事件到有限状态的映射。when 只做已公开字段的相等匹配，不执行 JS 表达式；超时计时器由宿主管理。

事件按宿主接收顺序处理；进入新状态时取消旧状态的定时器。cheer 等状态须在场景样式中有对应定义；生产版的清单与场景校验应检查所有引用，未定义状态视为包错误。以下 HTML/CSS 仅为概念切片，省略了样式引用和部分状态，不是完整场景文件。

</div>

04“挤开”与“戳出去”是两种能力

Reservation：角色占空间，按钮真的移动

角色进入捣蛋状态时，宿主在 toolbar.actions 的逻辑起始边插入占位轨道，把 Grid/Flex 中的真实按钮向旁边排开。结束后释放占位，DOM 身份、焦点与事件处理器不变。仅对角色或按钮使用 transform 不能改变兄弟元素的布局，也不应冒充排斥能力。

v0.1 只支持边缘槽位和面板 inset，不支持任意多边形障碍、二维碰撞或物理推挤。可用宽度不足时，宿主先缩小占位，仍不足就返回零占位并让角色移到备用锚点或隐藏。多个请求按稳定优先级顺序分配，合计不得侵占控件最小宽度。

宿主返回实际分配的 acceptedSize 和原因，场景据此摆位；不允许角色按“申请 112”绘制，而按钮只让出 40。指针按下、拖拽或键盘操作正在进行时延后变更，避免按钮从用户手下逃走。

Bleed：越过面板边框，仍在应用视口内

机甲的武器挂在根级 SkinStage，跟随被锚定面板的位置绘制，绕过该卡片及其滚动容器的裁切。bleed 是允许伸出的最大范围，最终取皮肤请求、宿主安全区、视口边界的交集。它不参与布局，不自动推开其他面板。

overflow: visible 不能穿过 iframe、WebView 或原生窗口的边界。装饰 renderer 必须覆盖宿主允许的 stage，而不是塞进一张小卡片 iframe。所谓“破框”指应用内部面板；真正伸到操作系统桌面需要额外透明窗口与系统级命中处理，明确不属于本协议。

图层与命中

宿主固定合成顺序：background → content → ornament-front → host-popover → host-modal → emergency-controls。皮肤只能选允许的层，不得提交任意全局 z-index。前景装饰默认 pointer-events: none，不得遮住开始/停止等保护区或焦点环。

需要“戳一下角色”时，由宿主生成有大小上限、名称和键盘行为的 hotspot，验证其不覆盖关键控件后再投递场景事件。不要让透明的全屏 iframe 接管整个窗口的鼠标。

05状态可以驱动皮肤，动作必须经过宿主

皮肤只获得公开视图模型，例如 task.runState（idle / running / paused / success / error / cancelled）、归一化进度、当前明暗模式、动效偏好以及已注册锚点的矩形。它不读取整个 Zustand store、任务密码、原始日志、文件路径或设备凭据。状态由宿主裁剪后推送，不能反向修改。

L1 的点击、超时和任务状态事件映射为 CSS 属性或有限场景状态；完成时角色欢呼，失败时灯光变色，运行时反应堆发光，都不需要作者脚本。宿主实现应区分“任务完成”和“成功”，取消/失败不能播放成功反馈。

v0.1 业务操作由真实宿主控件触发。未来可公开 requestAction("task.start") 这类语义接口，但必须校验消息来源、允许的 action、最新运行状态与真实用户手势，继续经过 MXU 现有启动流程；不能开放 invoke(command, args)、任意 HTTP、文件读写或通用状态 setter。纯场景事件不等于执行自动化的权限。

最小桥接只需三类信息：宿主向场景发 state/anchors/preferences；场景提交预先声明的 reservation；宿主返回 reservationResult 与点击事件。L1 由受信任 runtime 代办，作者无需调用 SDK。不同页面实例的消息携带 generation，切换皮肤后丢弃旧消息。

06MXU 只新增五项职责

  1. SkinLoader：解包、schema 校验、版本协商、资源索引和可回滚启用。安装成功不代表马上替换当前皮肤。
  2. AnchorRegistry：公开稳定的槽位名和矩形；通过 ResizeObserver、滚动监听和合并后的帧更新同步位置。名称属于协议，CSS 类名不属于协议。
  3. LayoutCoordinator：分配边缘占位、保护控件最小尺寸，返回实际布局结果；响应窗口缩放、语言变化和移动布局。
  4. SkinStage：管理前后装饰层、越框裁切、hotspot、动效生命周期和受信任的紧急恢复入口。
  5. SkinBridge：从 Zustand 派生只读状态，验证消息、调度声明式事件并管理卸载。保留原有业务服务与操作权限。

皮肤卸载须清除定时器、观察器、资源 URL、占位和事件订阅。应用崩溃后再次启动，可在主界面渲染前禁用最后启用的皮肤并回到内置主题。

07导入文件是一条独立的信任边界

建议生产版 L1 使用覆盖允许区域的隔离装饰 renderer：加载受限 HTML/CSS/SVG，使用受信任 bootstrap 接收消息；用户片段不能执行脚本。宿主 React 控件留在主文档。Shadow DOM 可避免样式串扰，但不是安全沙箱。

若采用 iframe，使用不含 allow-same-origin 的 sandbox；仅在受信任 bootstrap 必须运行时给予 allow-scripts，并以严格 CSP nonce/hash 限定执行者。不要同时给不可信同源内容这两项权限。禁止弹窗、导航、表单和下载；桥接使用绑定实例的 MessageChannel，校验消息结构与额度，不能把 origin === "null" 当作身份凭证。Tauri 的权限桥接是否隔离必须在各平台 WebView 实测。

  • ZIP：拒绝绝对路径、..、符号链接、重复/大小写冲突路径与超限条目；流式计算实际解压体积，防止 ZIP bomb。建议初始上限：压缩包 20 MiB、解压 60 MiB、256 文件、单文件 16 MiB，后续用实测调整。
  • 资源：只读包内索引，禁止网络资源、任意 file: 和系统路径；限制图像解码后尺寸，检查实际 MIME。SVG 必须消毒，移除脚本、事件属性、外链与 foreignObject。
  • HTML/CSS：使用成熟解析器及 allowlist，不能用正则过滤。禁止 script、iframe、object、embed、表单与事件属性；检查所有 CSS URL、@import、字体来源和嵌套规则。img-src、font-src、connect-src、form-action 等由独立 CSP 封闭。
  • 宿主：皮肤不能接触 Tauri 全局对象、invoke、WebUI API 或原生权限。当前项目主窗口配置有 withGlobalTauri: true、csp: null，所以直接向主文档注入第三方 HTML/JS 不可作为实现方案。

包导入在暂存区完成校验，预览确认后原子切换，失败恢复上一个可用皮肤；更新不自动增加权限。内置包走同一校验通路。未来 L2 应单独设计无原生权限、默认无网络、可终止的隔离执行域；不把任意 JavaScript 作为 L1 的隐藏开关。

08降级、无障碍与动效预算

宿主先检查 schema 与 required capabilities，再检查锚点是否存在。非当前视图的锚点视为暂不可见；隐藏相关装饰并释放占位。旧客户端不支持场景时可降为 L0，未知 required 能力必须拒绝启用；不能悄悄忽略必需字段。新增字段应由 schema 明确标注为可选，不使用随意容忍拼写错误的解析器。

为兼容不同 WebView，基础方案优先 Grid/Flex、CSS 变量、SVG 和经典关键帧。CSS anchor positioning、复杂滤镜、WebGL、Lottie/Rive 可在以后作为独立能力检测与适配器加入；协议不以某一个动画库为核心。

  • 可操作性：宿主控件保留文本替代、键盘焦点和足够对比度。角色装饰对读屏隐藏；hotspot 有本地化名称。错误/停止入口和恢复默认皮肤入口保持可见，不由皮肤接管。
  • 减弱动效：响应系统 prefers-reduced-motion 和 MXU 手动设置，关掉循环弹跳、强闪光与大幅视差；布局需求仍可生效，但瞬时或短淡变完成，不能因关动画而失去功能。
  • 运行预算：建议默认最多 4 个持续动画角色，状态与锚点更新合并至每帧一次；占位只在状态切换时变化，避免用每帧重排模拟物理。离屏、窗口隐藏或后台时暂停表演。
  • 性能退化：以普通设备实测帧耗时和内存为准，持续超预算则关闭滤镜/粒子、改静态图，最终移除场景保留 tokens。JavaScript watchdog 不能中断任意 CSS 渲染卡顿，因此导入时还需限制节点数量与昂贵效果。

这里的数值是实现起点，不是已经测得的 MXU 性能承诺。宿主同时需要测试中文/英文长标签、125%/150% 缩放、窄窗口、右侧面板折叠、移动端 WebUI，以及运行中切换皮肤。

10当前 demo 证明什么

演示器包含捣蛋团子、机甲、生态舱、黑胶、纸张、声呐六个内置场景，分别探索角色占位、装饰越框，以及状态驱动生长、旋转、印章和扫描；同时提供减弱动效、布局轮廓和运行模拟。它证明标准 Web 技术可以表达这些视觉行为，帮助讨论协议的边界与交互手感。

实现边界：demo 的场景代码是可信内置内容，使用本地模拟任务；它没有接入 MaaFramework，也不是生产级皮肤沙箱。演示器导入/导出的 mxu-skin-demo/0.1 JSON 仅描述名称、六种内置场景选择、受限十六进制色值、场景数值参数与效果开关，不等于 .mxuskin 安装器，不会执行导入文件中的 HTML/CSS/JS。本页正式 manifest 是待实现的规范样例。实验场的代码窗是概念切片，不能作为完整规范对象或安装文件直接复制使用。

当前占位 demo 使用有百分比上限的 Flex 轨道证明真实重排；完整的占位结果回传、交互期间延后移动、保护区域裁切和隔离导入仍需在 MXU 宿主实现。演示器中切换场景会重置模拟任务，生产版换肤则应保持业务任务继续运行。
