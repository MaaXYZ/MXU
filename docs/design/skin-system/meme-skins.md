# 白饭鲸鱼娘与奶蛙

这两套皮肤是基于网络热梗制作的**非官方社区二创场景**，已作为可信内置皮肤接入 MXU 的外观设置与任务主视图；本目录同时保留它们在离线概念 demo 中的版本。白饭鲸鱼娘使用现有社区公开视频及同源透明抽帧。奶蛙使用公开可访问的社区大笑视频、海报与原片第 1 秒的闭口静态截帧。最终两套均不包含本次生成或重绘的角色图。素材来源和权利状态见文末。

两套只展示公开素材中的动作，不添加角色对白、拟声台词或额外剧情；界面文字只表达宿主任务状态与操作提示。

## 主程序体验

在 **设置 → 外观 → 内置皮肤** 中选择默认、蓝色大肥鱼吃白饭或奶蛙。原有明暗模式和强调色继续保留，皮肤不会覆盖用户配色。设置页提供预览，角色在任务主视图的工具栏前以普通布局卡片出现；默认选项移除卡片。减少动效同时遵循系统请求与皮肤设置。

主程序卡片只消费活动实例已有的运行、整批成功和整批失败事实，其余显示待机；角色互动不调用任务命令。停止后任务状态为 `null` 时不会假装成功或取消，也没有从时间或动画计算的百分比。换肤保持业务任务执行，桌面选择按项目外观配置保存，WebUI 选择保存在浏览器本地且不会覆盖桌面选择。

组件与素材随前端发布，资源固定在 `src/assets/skins/`。本次没有通用 Manifest 解释器或第三方 `.mxuskin` 安装入口，也没有新增作者脚本、文件或网络能力。

## 离线 Demo 中的两套设计

以下主题色、可调幅度、进度条、暂停与取消均属于独立模拟器。它们不代表主程序任务适配器已经提供相同字段或操作。

**蓝色大肥鱼吃白饭**采用既有社区动画中的蓝发鲸鱼娘：鲸鳍、呆毛、大鲸尾、蓝白女仆装与白饭碗。主题色为 `#225fbd`，互动仅播放原有吃白饭动作，不改变任务进度或执行结果。待机、吃饭与错误静态图分别从同源公开视频抽帧，保留透明，没有重绘角色。

**奶蛙**以实际大笑原片为准：没有描边的三维黄色梨形身体、头身相连的圆滑轮廓、浅色肚皮、绿色眼睛与黑瞳、黄色有肉的手臂和腿，只有手掌及脚掌偏深褐。公开动作是双手捧腹、仰头张嘴、身体发颤。主题色为 `#667c28`；宿主互动按钮或任务成功反馈可以播放该动作，失败时停止播放，不为角色另添性格或台词。

两套均不播放音频，原片音轨不作为本皮肤内容分发。模拟器的文字状态、模拟进度和任务结果始终保留，角色动作不承担唯一的状态提示；系统或页面开启“减少动效”时使用静态姿态并保留客观任务文字。

奶蛙随包视频基于该站提供的 720×982、15.4 秒 H.264 播放版本，移除音轨、剪去开头 2.6 秒的安静片段，保留 12.8 秒大笑动作；海报为同一条目的本地 WebP，`naiwa-calm.png` 是未裁剪原视频第 1 秒的闭口静态截帧。无需运行时 seek，进度更新与重复触发不会跳转或重播。视频白底通过装饰列的 CSS 混合融入背景，不依赖远程播放器或在线抠像服务。两套静态姿态都只取自原片，不重绘。

| 触发或状态 | 白饭鲸鱼娘 | 奶蛙 |
| --- | --- | --- |
| 待机 | 待机静态帧，显示待机状态 | 中性静态姿态，显示待机状态 |
| 互动动作 | 宿主按钮播放吃白饭动作，约 2.4 秒后复位 | 宿主按钮播放捧腹大笑动作，约 2.4 秒后复位 |
| 运行 | 显示执行中；动作不代表任务进度 | 显示执行中；动作不代表任务进度 |
| 暂停 | 停止互动，显示已暂停 | 停止互动，显示已暂停 |
| 成功 | 显示任务完成 | 播放原有捧腹大笑动作，显示任务完成 |
| 失败 | 同源错误静态帧，显示执行失败 | 停止大笑，显示执行失败 |
| 取消 | 停止互动，显示本次已取消 | 停止互动，显示本次已取消 |

离线 demo 的角色互动仅在待机和运行时可用，暂停和终态由模拟任务状态控制。失败与取消会清除未结束的互动，不触发成功庆祝；互动超时只复位角色，不修改任务事实。切换场景会重置本 demo 的模拟任务；主程序的内置皮肤切换则保持实际业务任务。

## 白饭鲸鱼娘素材与许可

来源为 [PC2005-cloud/dsh-pet](https://github.com/PC2005-cloud/dsh-pet)，固定提交 `33938a355f422525886c3facd883d7179c58ebf4`。主程序与离线 demo 使用相同来源的本地副本：

| 本地文件 | 原文件 | 本次处理 |
| --- | --- | --- |
| `deepseek-eat.mp4` | [吃白饭.webm](https://github.com/PC2005-cloud/dsh-pet/blob/33938a355f422525886c3facd883d7179c58ebf4/dsh-pet/assets/webm/%E5%90%83%E7%99%BD%E9%A5%AD.webm) | libvpx 解码 VP9 alpha、合成白底、移除音轨并转为 H.264，保留约 10.04 秒原动作 |
| `deepseek.png` | 同上 | 4 秒处抽帧为透明 PNG |
| `deepseek-calm.png` | [待机呼吸休闲.webm](https://github.com/PC2005-cloud/dsh-pet/blob/33938a355f422525886c3facd883d7179c58ebf4/dsh-pet/assets/webm/%E5%BE%85%E6%9C%BA%E5%91%BC%E5%90%B8%E4%BC%91%E9%97%B2.webm) | 1 秒处抽帧为透明 PNG |
| `deepseek-error.png` | [工作状态-垂头叹气冒汗.webm](https://github.com/PC2005-cloud/dsh-pet/blob/33938a355f422525886c3facd883d7179c58ebf4/dsh-pet/assets/webm/%E5%B7%A5%E4%BD%9C%E7%8A%B6%E6%80%81-%E5%9E%82%E5%A4%B4%E5%8F%B9%E6%B0%94%E5%86%92%E6%B1%97.webm) | 4 秒处抽帧为透明 PNG |

动画素材署名 **PC2005-cloud**；原型「溟月」署名 **上善无形**；DeepSeek 女仆鲸鱼娘设计署名 **ZipZipPipe**。来源 [README 的许可说明](https://github.com/PC2005-cloud/dsh-pet/blob/33938a355f422525886c3facd883d7179c58ebf4/README.md#许可)将代码 MIT 与素材授权区分，素材按角色的 [CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/deed.zh-hans) 保留署名、非商业与相同方式共享条件；形象许可可核对 [ZipZipPipe 的原声明](https://www.bilibili.com/opus/1247156596114456581)。这些媒体不适用代码许可证。随附 [来源与处理说明](../../../src/assets/skins/README.md) 及 [许可摘要](../../../src/assets/skins/LICENSE.deepseek.txt)保留上述记录。

原 VP9 alpha 视频在不支持透明 WebM 的平台可能出现黑底，因此随包视频使用白底 H.264；主程序使用白色肖像框，离线 demo 将白底混入背景。减少动效、播放失败或格式不支持时使用同源静态帧。此处理不构成各平台 WebView 解码兼容性的保证。
